# AgenticLab Knowledge Router — exp4

- **Scope:** `project:exp4`
- **Canonical project-record collection:** `AgenticLab/knowledge/records/`
- **Retrieval:** `readKnowledgeRecords` searches the active project-record tree recursively. Maps are navigation aids, not exhaustive inventories; a complete eligible-record scan—not map membership—is required for a no-match claim.

## Navigation

- **Project records:** `records/` — authoritative, searchable independently of map links; this index intentionally does not enumerate every record.
- **Backend engineering map:** [Backend Engineering](maps/backend.md) — curated routes for API ownership, schema/migration alignment, and isolated API testing; scope `project:exp4 / backend`.
- **PBI1 decisions:** [PBI1 Decisions](MOC.md) — scope: `exp4 / pbi1`.

Other topic maps may be added here when they provide a useful route. Keep each map's collection and scope explicit. Do not widen or repurpose an existing PBI-specific map merely to include general backend guidance.
